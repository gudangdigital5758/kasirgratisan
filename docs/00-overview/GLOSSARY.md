# Glossary

- **Profitku**: customer-facing platform and billing authority.
- **MSC Studio**: media generation infrastructure.
- **9Router**: LLM routing layer for AI Marketing and AI Coding only.
- **Wallet**: customer prepaid balance.
- **Ledger**: financial transaction history.
- **Reservation**: temporary wallet hold before final usage is known.
- **Capture**: final charge of a reservation.
- **Release**: return of unused reservation.
- **Idempotency**: repeated request produces one logical financial effect.
- **AI Usage**: measured input/cache/output token consumption.
