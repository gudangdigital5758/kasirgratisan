# System Boundaries

## Profitku owns
- Users
- Authentication
- Customer billing
- Wallet
- Subscription
- Pricing
- Admin
- AI Marketing
- Customer AI usage metering

## MSC owns
- Image generation
- Video generation
- Telegram generation
- Media provider integrations
- Media workers/queues

## 9Router owns
- LLM routing for AI Marketing
- LLM routing for AI Coding

## Explicit boundary
9Router is not an MSC media provider router.
