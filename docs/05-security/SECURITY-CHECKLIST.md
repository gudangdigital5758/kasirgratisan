# Security Checklist

- [ ] Secrets not committed
- [ ] Secrets not sent to frontend
- [ ] Admin RBAC enforced server-side
- [ ] OAuth callback protected
- [ ] CSRF/state protections verified where applicable
- [ ] Rate limits
- [ ] Input validation
- [ ] SSRF review
- [ ] Log redaction
- [ ] Dependency audit
- [ ] Network isolation
- [ ] Backup encryption/access control
