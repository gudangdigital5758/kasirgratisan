# AI TASK PROTOCOL

For every implementation task:

1. Read `AGENTS.md`.
2. Check `PHASE-0-GATE.md`.
3. Check `PROJECT_STATUS.md`.
4. Identify the task domain.
5. Read only the relevant PRD/architecture/API/database/security/ADR documents.
6. Inspect current source code.
7. State the intended change and affected surfaces.
8. Implement the smallest safe change.
9. Run relevant validation.
10. Review security/financial impact.
11. Update documentation and progress.
12. Report changes, tests, risks, and commit message.

If Phase 0 is incomplete, implementation is blocked; perform audit/discovery only.
